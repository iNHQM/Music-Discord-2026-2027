# NHQM Music Bot — Advanced Discord Music System

**NHQM Music Bot** is an advanced Discord music system developed using Node.js and Discord.js, designed to provide high-quality music playback, automated voice channel management, and centralized control over multiple music bots.

The system features a custom web-based dashboard that allows users to manage multiple Discord music bots simultaneously through a modern, interactive interface.

### Key Features

- **Multi-Bot Management:** Run and manage multiple Discord music bots independently.
- **Music Playback:** Search for and play music directly through Discord voice channels.
- **Web Dashboard:** A custom control panel featuring a dark, futuristic interface with interactive elements and animations.
- **Real-Time Monitoring:** Monitor bot status, active tracks, playback queues, and volume levels.
- **Playback Controls:** Pause, resume, skip, stop, and repeat music.
- **Volume Management:** Adjust audio levels through Discord controls.
- **Voice Channel Integration:** Connect bots to configured Discord voice channels.
- **Interactive Discord Panels:** Manage playback using embedded messages and interactive buttons.
- **Automated Audio Processing:** Process and stream audio using FFmpeg and yt-dlp.
- **Centralized Bot Controls:** Start or stop individual bots or manage the entire bot network simultaneously.
- **REST API Integration:** Connect the web dashboard to the backend for bot monitoring and control.

### Technologies

Node.js, JavaScript, Discord.js, Discord Voice API, Express.js, REST APIs, HTML5, CSS3, FFmpeg, yt-dlp, Web Development, Audio Streaming.

### Project Goal

To build a powerful, scalable, and efficient Discord music infrastructure that combines advanced audio playback, multi-bot automation, and centralized web management into a seamless and professional music experience.
